دل‌دونه — قالب اولیه وب‌سایت پیشنهاد هدیه

فایل‌ها:
- index.html: صفحه اصلی به همراه تست نمونه تعاملی
- blog.html: آرشیو بلاگ
- article.html: صفحه تکی مقاله
- about.html: درباره ما
- contact.html: تماس با ما
- style.css: استایل مشترک و واکنش‌گرا
- script.js: منطق تست نمونه و پیام نمایشی فرم تماس

برای مشاهده، index.html را در مرورگر باز کنید.
تصاویر و فونت‌ها از منابع آنلاین بارگذاری می‌شوند.
تست فعلی یک نمونه نمایشی با منطق ساده است و به API هوش مصنوعی متصل نیست.
برای اتصال AI، ذخیره جواب‌ها، پیشنهاد محصول واقعی و ارسال فرم باید بک‌اند و سرویس‌های مربوط اضافه شوند.
